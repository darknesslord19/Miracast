# Ekran Yansıt (Miracast benzeri)

Android telefonun ekranını ve sesini Android TV'ye Wi‑Fi üzerinden aktarır.

**İndir:** [Son APK](https://github.com/darknesslord19/miracast/releases/latest/download/EkranYansit.apk)

## Kurulum
1. Aynı APK'yı hem telefona hem Android TV'ye kurun.
2. TV'de uygulamayı açın — otomatik olarak alıcı modunda başlar ve "Hazır" yazar.
3. Telefonda uygulamayı açın, TV listede otomatik görünür, **Yansıtmayı Başlat**'a basın.

## Özellikler
- Otomatik TV bulma (aynı Wi‑Fi ağında)
- 1080p 60fps H.264 donanım kodlama, düşük gecikme
- Ses aktarımı (Android 10+)
- Bağlantı koparsa otomatik yeniden bağlanma; ağ yavaşlarsa gecikme birikmeden toparlanma
- Telefon döndürülünce görüntü otomatik yön değiştirir
- İsteğe bağlı: uygulama açılınca otomatik yansıtma

## Notlar
- Android güvenlik kuralı gereği ekran paylaşım onayı her başlatmada sorulur.
- Bazı uygulamalar (Netflix vb.) görüntü/ses yakalamayı engeller; bu durumda siyah ekran veya ses gelmez.
- APK GitHub Actions ile otomatik derlenir (`.github/workflows/build.yml`).
